# ADR 0003: Мессенджер живёт в этом репозитории

## Статус

Принято

## Контекст

Проектирование (`docs/messenger/04-decisions.md`) предполагало три репозитория:
`messenger-app` — что запускаем, `messenger-infra` — где, `messenger-gitops` —
какая версия где. План исполнения повторил это как `G0-001…003`.

На старте G0 решение было пересмотрено: описание мессенджера в GitOps положено
в `gitops/04-messenger/` этого репозитория, рядом с платформенным слоем, а не
в отдельный репозиторий.

## Решение

Мессенджер — код, схема базы, контракты, чарты и GitOps — живёт в
`kubernetes-finops-platform`.

```
apps/messenger/        сервисы
packages/contracts/    OpenAPI, схемы Kafka и WebSocket
db/                    миграции и исполнитель
charts/messenger/      чарты сервисов
gitops/04-messenger/   что и в каком порядке разворачивается
```

Разделение на три репозитория остаётся правильным для настоящей команды и
возвращается тогда, когда появляется то, ради чего оно делается: разные права
доступа, разные темпы выкатки, разные владельцы.

## Обоснование

Три репозитория решают организационную задачу, а не техническую. Их польза —
границы ответственности между людьми. Пока автор один, они дают только
издержки: тройное изменение при любой правке контракта, три конвейера CI,
которые нужно держать согласованными, и невозможность атомарного коммита,
меняющего схему события вместе с его потребителем.

Отдельно важно, что цена обратного перехода низкая, а цена преждевременного
разделения — нет. Разрезать один репозиторий на три можно в любой момент
механически, сохранив историю. Свести три обратно в один, когда между ними уже
накопились расхождения версий, значительно дороже.

## Последствия

- `G0-001…003` закрываются структурой каталогов, а не созданием репозиториев.
- Политика веток остаётся прежней: единственная `main`, окружения живут
  в `gitops/`, а не в ветках.
- Конвейер CI один, но задания разделены по путям: изменение контракта не
  запускает сборку образов.
- Когда разделение понадобится, границы уже проведены каталогами — это и есть
  подготовка к нему.
