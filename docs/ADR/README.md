и у него была отвергнутая альтернатива. Всё остальное живёт в коде и в

## Что записывать

```
записывать                         не записывать
──────────                         ─────────────
выбор между двумя работающими      как называть переменные
вариантами                         очевидное следствие уже принятого
принятый риск                      то, что легко изменить обратно
отвергнутая альтернатива
```

Запись без отвергнутой альтернативы обычно означает, что выбора не было, —
тогда это не решение, а описание. Оно принадлежит документам проектирования.

**Принятые записи не переписываются.** Решение отменяется новой записью,
которая ссылается на предыдущую; история живёт в git, а не в оговорках внутри
файла. Иначе через полгода нельзя понять, что знали на момент выбора.
