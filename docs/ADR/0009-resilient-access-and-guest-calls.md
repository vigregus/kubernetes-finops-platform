# ADR 0009: Устойчивый браузерный доступ и звонки по ссылке

## Статус

Предложен

Дополняет [ADR 0007](0007-calls-after-web-push.md). Номер 0008 занят под поиск контактов.

## Контекст

Звонки 1:1 работают через WebSocket-сигнализацию и прямое WebRTC с запасным релеем coturn
на UDP. Любая из этих опор по отдельности блокируется (UDP, WebSocket, единственный TURN).
Отдельно владельцу нужны звонки по ссылке для человека без аккаунта.

## Решение

1. **Устойчивость — цепочка стандартных транспортов**, а не собственный протокол:
   realtime `WebSocket → SSE → HTTPS polling`; медиа `direct → STUN → TURN UDP → TCP → TLS :443`;
   несколько TURN за `CompositeTurnProvider`. Абсолютная защита от блокировки не обещается.
2. **Только браузер.** Нативный клиент и собственный wire protocol вне плана.
3. **Гостевая ссылка — capability на одну комнату**: секрет во fragment, обмен на краткоживущую
   `GuestSession`, один гость, TTL 15 минут, права ограничены комнатой.
4. **Гость не `User`.** Участник звонка — `CallPrincipal` (`user_id` либо `guest_session_id`, ровно одно).
5. **TURN-доступ выдаётся только после допуска в комнату.**
6. Реализация — десятью отдельными PR по порядку из [части 18](../messenger/18-resilient-access-and-guest-calls.md#23-порядок-реализации).

## Отвергнутые альтернативы

| Вариант | Почему нет |
| --- | --- |
| Собственный фреймовый протокол поверх TCP/UDP | становится устойчивой сигнатурой для DPI; браузер всё равно не умеет сырые сокеты |
| Гость как временный `User` | смешивает аккаунт и право на одну комнату, тянет за собой поиск, беседы, лимиты |
| Секрет в query-параметре | уходит на сервер, в журналы и в `Referer` |
| Один TURN | единая точка блокировки |

## Последствия

- Часть сетей остаётся способной закрыть сервис целиком — принято.
- `call_participants` меняется (`principal_type`, `guest_session_id`): миграция по правилам [ADR 0006](0006-expand-contract-migrations.md).
- Нужен домен для страницы гостя и TLS на :443 у TURN.
- Гостевые звонки включаются только после защиты от злоупотреблений (`LINK-006`, `CALL-017`).
