# Vector — дизайн-система мессенджера

Storybook — единственное место, где описаны компоненты интерфейса: каждый показан в своих состояниях, а проверки в `play` исполняются как тесты. Токены (цвета, шрифты) — в разделе **Foundations**.

## Уровни

Раздел боковой панели — это уровень компонента. Правило простое: компонент знает только уровни **ниже** себя.

| Уровень | Что это | Примеры |
| --- | --- | --- |
| **Atoms** | Неделимый элемент без знания о мессенджере | `Avatar`, `Badge`, `Icon`, `IconButton`, `StatusDot`, `TextField`, `SearchField`, `DayDivider`, `SyncIndicator`, `TypingIndicator` |
| **Molecules** | Несколько атомов с одной задачей | `ConversationListItem`, `ChatHeader`, `MessageBubble`, `MessageComposer`, `AttachmentBubble`, баннеры и заглушки |
| **Organisms** | Самостоятельный участок экрана | `ConversationSidebar`, `MessageList`, `MessageTimeline`, `SessionsPanel` |
| **Templates** | Раскладка без данных | `MessengerLayout` (экраны `both`, `list`, `chat`) |
| **Pages** | Экран с данными и состояниями | `ChatPage`, `LoginPage`, `SettingsSessionsPage` |

## Правила

- **Элемент без действия не рисуется.** Кнопка без обработчика не показывается вовсе: кнопка, которая ничего не делает, хуже отсутствующей. Поэтому в мобильном интерфейсе нет вкладок «Channels», «Calls», «Profile», поиска по чатам, фильтров «Unread» и «Favorites», а также подписи «Encrypted»: этих функций в мессенджере нет.
- **Не утверждаем того, чего сервер не говорил.** Присутствие рисуется только если сервер его сообщил; число непрочитанного — только если пришло.
- **Решает JavaScript, а не только стили.** На узком экране панель беседы не монтируется, пока её не открыли: спрятанная стилем, она держала бы соединение и отмечала прочитанным то, что человек не открывал (`useIsMobile`).
- **Состояния — это истории.** Загрузка, пусто, ошибка, блокировка — отдельные истории, а не флажки в одной.

## Телефон и планшет

В панели вьюпорта Storybook есть пресеты **Phone 390×844**, **Small phone 360×640** и **Tablet 820×1180**. Мобильная раскладка включается ниже 768 px (`md` у Tailwind): список бесед и беседа занимают экран по очереди, «назад» — шаг истории браузера (системный жест возвращает к списку), вырезы экрана учтены (`pt-safe`, `pb-safe`, `viewport-fit=cover`).

Широкий экран: левая колонка сворачивается в узкую (аватары с числом непрочитанного), выбор запоминается в браузере; истории `Organisms/ConversationSidebar → WithCollapseToggle`, `Collapsed`.

Мобильные истории: `Organisms/ConversationSidebar → Mobile`, `Molecules/ChatHeader → MobileWithBack`, `Molecules/MessageComposer → Mobile`, `Templates/MessengerLayout → MobileList`, `MobileChat`, `Pages/ChatPage → Mobile` (список → беседа → назад).

## Как добавить компонент

1. Определить уровень и положить историю с `title: "<Уровень>/<Имя>"`.
2. История на каждое состояние; для интерактивных — `play` с проверкой (`expect`, `userEvent`).
3. Для экранов, меняющихся на телефоне, — история с `globals: { viewport: { value: "phone" } }`.
4. Новые цвета и шрифты — только через токены из `index.css` (`@theme`), не литералами.
