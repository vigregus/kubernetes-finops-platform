# Беседы: `GET /conversations` → модель списка

Таблица соответствия живёт в `adapter.ts`, время последнего сообщения — в
`formatTimestamp.ts`. Оба файла существуют затем, чтобы каждое поле интерфейса
либо выводилось из ответа сервера, либо было объявлено отсутствующим. Третьего
не бывает: значение, которого сервер не сообщал, — это утверждение о нём.

## Поля

| Поле модели | Источник | Когда источника нет |
| --- | --- | --- |
| `id` | `conversation_id` | — |
| `name` | `direct` — `display_name` **единственного** участника с `user_id !== currentUserId`; `group` — `display_name` **всех остальных** через «, » | имён не осталось → нейтральное `Group`. Пустой строки и `undefined` не бывает |
| `initials` | — | не заполняется: `Avatar` считает инициалы из `name` (`shared/ui/Avatar.tsx:21`), и второе представление того же разошлось бы с первым |
| `avatarUrl` | — | отсутствует: хранилища аватаров в контракте нет |
| `presence` | `direct` — `online` собеседника через `presenceOf`: `true` → `"online"`, `false` → `"offline"`; `group` — не заполняется (одно слово на группу смысла не имеет, как и `lastSeenAt`) | ключа нет или он `undefined` → `undefined`, и подзаголовка нет вовсе. Три исхода, а не два: `online ? "online" : "away"` сказала бы «Away» на ответе без ключа, то есть утверждала бы о человеке то, чего сервер не сообщал. `"away"` не производится ничем: сервер знает только «активность не подтверждена окно» (`domain/presence.py`) |
| `lastSeenAt` | `direct` — `last_seen_at` собеседника; `group` — не заполняется | ключа нет или `null` → `undefined`. Одно значение на группу смысла не имеет |
| `unreadCount` | `unread_count` | ключа нет → `undefined` — **«неизвестно»**, а не `0` |
| `lastMessagePreview` | таблица превью ниже | `last_message` нет → `""` |
| `previewDeleted` | `Boolean(last_message?.deleted_at)` | нет сообщения → `false` |
| `lastMessageTimestamp` | `formatConversationTimestamp(last_message.created_at, now)` | нет сообщения → `undefined`; выдуманного «только что» не бывает |
| `typingNames`, `blockedByMe`, `blockedMe` | — | отсутствуют, и указатель здесь был неверен в обе стороны: «печатает» — это `G4`, а у `blocked*` гейта нет вовсе — в контракте их нет ни в одном поле. `G3-007` их не заводит: он маскирует присутствие и квитанции **отсутствием** (маска блокировки, `docs/messenger/04-decisions.md`), а не флагом, и поля модели остаются без источника |

**Почему у адаптера есть `currentUserId`.** `GET /conversations` отдаёт
участников **включая самого зрителя**: подзапрос собирает всех действующих
участников беседы (`repositories/conversations.py:87-95`), а внешний отбор
ограничивает только то, чьи беседы мы читаем (`WHERE cm.user_id = $1`). Значит
для личной беседы `participants` содержит двоих, и «собеседник» — это участник с
другим `user_id`, а не `participants[0]`; порядок задаёт
`ORDER BY cm2.joined_at, cm2.user_id`, и зритель вполне может оказаться нулевым.
Подстановка `participants[0]` показала бы человеку его же имя под именем
собеседника.

**Почему `now` и локаль — параметры.** Скрытый `Date.now()` и зона машины
сделали бы тесты зависимыми от календаря и от того, где их запустили: «14:22»
превращалось бы в «16:22» в Берлине и «22:22» в Токио. В интерфейсе значения по
умолчанию — локаль и зона браузера; в тестах передаются явно.

## Превью последнего сообщения

`MessagePayload` не имеет обязательных полей, и `payload` может отсутствовать
целиком. Пустая строка здесь — не заглушка: компонент уже понимает её как
«сообщений нет» (`components/ConversationListItem.tsx:26`) и рисует своё «No
messages yet». Адаптер кормит существующую ветку, а не заводит второй текст для
того же состояния.

| Вход | `lastMessagePreview` | Что видно |
| --- | --- | --- |
| `last_message` нет | `""` | существующее «No messages yet» |
| `deleted_at != null` | `Message deleted` | иконка «block» + курсив (`previewDeleted`) |
| `type: text` и непустой `payload.text` | текст | — |
| `type: text` без `payload.text` | `Message` | — |
| `type: image` | `Photo` | — |
| `type: file` | `File` | — |
| `type: voice` | `Voice message` | — |
| `type: system` и любое неизвестное | `Message` | — |

Надгробие сильнее содержимого: у удалённого сообщения `payload` может уцелеть, и
показать его — значит показать то, что человек удалил.

**Фолбэки — на языке интерфейса, то есть английском.** `Group`, `Photo`, `File`,
`Voice message`, `Message`, `Message deleted`. Русская строка посреди
англоязычного списка была бы скрытой продуктовой переделкой дизайна; i18n в
объём G3-005 не входит.

## Время последнего сообщения

`created_at` (ISO) → `14:22` (сегодня) · `Yesterday` (вчера) · `Sep 18`
(раньше). Прокинутый ISO дал бы `2026-09-20T14:22:31Z` прямо в списке: тип поля
`string`, `tsc` молчит, дизайн сломан.

Границы суток считаются в переданной зоне, а «вчера» — по календарю, а не
вычитанием 24 часов: в сутках перехода на летнее время их 25, и `now - 24h` мог
бы остаться теми же сутками. Неразбираемая отметка даёт `undefined`, а не строку
`Invalid Date` в списке.
